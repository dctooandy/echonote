# 統一的分享入口 規格

分支：`feature/share`
狀態：已完成（2026-11-06，實機確認），待併入 master

詳細頁現在有五個分散的分享相關入口，而且只有文字和 HTML 能傳，原始錄音傳不出去，LINE 也收不了 .html。這個分支改成一個「分享」入口，先選用途，再決定送出什麼。

## 現況（寫規格時查過的程式碼）

- `MeetingDetailScreen`：
  - 「⋯」選單：「複製成 LINE 訊息」（`_openLineMessage`）、「匯出會議紀錄」（`_exportMinutes`，寫暫存 .html 再分享）。
  - 摘要卡片「複製摘要」、逐字稿分頁「複製全部逐字稿」「匯出逐字稿」（`_exportTranscript`，寫暫存 .txt 再分享）。
  - `_shareFile` 可注入（`widget.shareFile`），測試用；一次只傳一個檔。
- `buildMeetingHtml`（`meeting_html.dart`）：單一 HTML，不含筆記、逐字稿、時間戳；已有列印樣式。
- `LineMessageScreen`：可以改字的預覽，AppBar 寫「LINE 訊息」。
- `RecordingStore.resolveAudioPath`：錄音檔路徑；檔案可能不存在。即時錄音是 .wav，檔案偏大。
- `share_plus` 的 `ShareParams.files` 可以一次帶多個檔。
- 專案沒有 PDF 相關套件，也沒有內建中文字型。

## 決定（2026-11-06，依照建議）

1. 三種情況：會後把結論傳給對方、把紀錄留給沒參加的人、交出完整資料讓別人查證。
2. 統一一個「分享」入口，先選用途，再顯示會送出什麼。
3. 各分頁就地的「複製摘要」「複製全部逐字稿」保留；「⋯」的「複製成 LINE 訊息」「匯出會議紀錄」和「匯出逐字稿」併進「分享」。
4. 「複製成 LINE 訊息」改名「傳給對方的結論」，內容不變。
5. 錄音放在「完整資料」，預設不勾，要主動選、多一步提醒。
6. 用手機內建的分享選單；紀錄提供 PDF；不上傳雲端、不做連結分享。
7. 個人筆記一律不帶。
8. 畫面選 A：底部選單選用途（[頁面](https://claude.ai/artifact/EYNp7dB7MufdzCQDHXMjy6)）。
9. 「分享」按鈕放詳細頁右上角，跟「⋯」並排。

## 目標與範圍

上面 1～9。

**明確不做的事**：不做連結分享或雲端上傳、不壓縮或轉檔錄音、不改分析和 prompt（不用部署、不用跑評測）、不做批次分享多場會議。

## UI／畫面

- AppBar 右上角「分享」按鈕，在「⋯」左邊；忙碌（分析、轉錄）時停用，跟「⋯」一樣。
- 底部選單「要分享什麼？」：
  - **傳給對方的結論**：開預覽（`LineMessageScreen`，標題改名）。沒有分析時停用。
  - **會議紀錄**：產生 PDF，開手機的分享選單。沒有分析時停用。
  - **完整資料**：第二層底部選單，逐字稿預設勾、錄音預設不勾（決定 12、5）。
- 「⋯」拿掉「複製成 LINE 訊息」「匯出會議紀錄」；逐字稿分頁拿掉「匯出逐字稿」。

## 邊界案例與例外處理

- **還沒轉錄**：完整資料裡逐字稿不能勾。
- **找不到錄音檔**：完整資料裡錄音不能勾，並寫明原因。
- **兩項都不能勾、或都沒勾**：「分享」按鈕停用。
- **產生 PDF 失敗**：SnackBar 說失敗。
- **分析過時**：結論已有提醒；紀錄先問（決定 13）。
- **使用者取消手機的分享選單**：回到詳細頁，不算失敗。

## 測試接縫

- **widget 測試**：按「分享」看到三個用途；沒有分析時前兩項停用；結論開預覽；紀錄把 PDF 交給 `shareFile`；完整資料預設只帶逐字稿；勾錄音要提醒、確認後才帶；取消提醒不送出；找不到錄音檔不能勾；「⋯」和逐字稿分頁的舊入口不見了。
- **純函式**：完整資料要送哪些檔、檔名。
- **PDF 內容**：只能實機看（轉檔靠手機系統）。
- **手動**：實機把 PDF 傳到 LINE，確認收得到、中文正常；傳逐字稿＋錄音到 AirDrop 或 Email。

## 實作備註

- **`Printing.convertHtml` 被套件標為 deprecated**（`printing` 5.15.1，寫規格時沒查到，實作時才發現）。仍在維護：最近的版本還修了它在 iOS 26 的閃退。先用，並在程式註明；替代做法是自己寫 Swift 呼叫 WKWebView，或用純 Dart 重畫並內建中文字型。
- `MeetingDetailScreen.shareFile` 改成 `shareFiles`（一次多個檔），另外可注入 `htmlToPdf`，測試不需要手機的 web view。
- 底部選單：`lib/widgets/share_sheet.dart`。
- 錄音檔大小用同步的 stat（`existsSync`、`lengthSync`），開選單前查一次。
- 加 `printing` 時，傳遞相依的 `image` 升到 4.11.0，跟鎖在 4.0.9 的 `archive` 編不過（`flutter analyze` 看不出來，要跑測試或編譯才會發現）；`flutter pub upgrade archive` 升到 4.6.0 解決。
- AppBar 從一顆按鈕變兩顆（決定 9），標題的空間變小，既有的「AppBar 只留一顆」測試跟著改。
