# 分析前標出詞庫的同音寫法 規格

分支：`feature/glossary-homophones`
狀態：已完成（2026-11-02，prompt `4545159f` 已部署，實機確認），待併入 master

`fix/glossary-owner` 用 prompt 修好了 C3（聽錯的「一針／乘汗」對到詞庫），但 C7 改不動：同一份逐字稿裡「小美」「小眉」都出現時，Haiku 4.5 會當成兩個人（1/5）。Haiku 5.5 medium 會合併（5/5），但 C3 只有 1/5。這個分支不再靠模型自己判斷同音，改成**分析前在程式裡找出逐字稿中跟詞庫讀音相同的寫法，送給模型時直接標出來**。

## 現況（寫規格時查過的程式碼）

- `buildUserMessage`（`functions/src/analyze.ts`）：詞庫照原樣一行一個放進 `<glossary>`。
- `SYSTEM_PROMPT` 第 210 行（prompt `41da1d10`）：已經寫了「讀音相同或相近的名字……視為詞庫裡的同一個人」。
- 詞庫最多 200 條、每條最多 20 字（`GLOSSARY_MAX_TERMS`、`GLOSSARY_TERM_MAX_CHARS`）。
- 帶詞庫的評測案例：C3（`蔡宜蓁、吳承翰` 等）、C7（`小美、Meetup、網域`）。
- 拼音套件 `pinyin-pro` 3.29.5（MIT、沒有其他相依套件、約 950 KB）。實測繁體字可以用，去掉聲調後：小美＝小眉（xiao mei）、網域＝網欲（wang yu）、蔡宜蓁＝蔡醫真（cai yi zhen）、宜蓁＝一針（yi zhen）、承翰＝乘汗（cheng han）、台積電＝太基電（tai ji dian）。

## 目標與範圍

1. 新增純函式：輸入詞庫和逐字稿，找出逐字稿裡「去掉聲調後讀音跟某個詞庫詞相同、但字不同」的寫法。
2. `<glossary>` 裡有找到同音寫法的詞，加上註記，例如 `小美（逐字稿裡也寫成：小眉）`；沒找到的照舊。
3. `SYSTEM_PROMPT` 補一句說明這個註記的意思。
4. 用 Haiku 4.5 量修改前、修改後（全部案例各 5 次），達標才問使用者部署；之後用同一份比較 Haiku 5.5 medium。

**明確不做的事**：不改 App、不改 request 格式、不處理英文詞（例如 Meetup／Mid-Up）、不換模型。

## 比對規則（草稿）

- 只比中文字：詞庫詞全部是中文字才比對；夾英文或數字的詞跳過。
- 把每一段逐字稿轉成去掉聲調的拼音（整段一起轉，讓多音字照上下文判斷），用跟詞庫詞一樣長的視窗滑過去，拼音相同、字不同就記下。
- 同一個詞有多種寫法時全部列出，依出現次數排序。
- 三個字的詞另外用後兩個字比對（決定 2）。
- 一個字的詞不比對（決定 7）。

## 邊界案例與例外處理

- **誤判**：兩個字的詞容易碰到不相干的同音詞（例如「網域」碰到「往於」）。註記只是提示，prompt 要寫明「請依上下文判斷」，不要求一律替換。
- **註記太多**：每個詞最多列 3 種寫法（決定 4）。
- **找不到**：照現在一樣送，user message 跟修改前一字不差（有測試）。
- **拼音套件出錯**：不擋分析，退回不加註記。
- **效能**：200 條詞庫 × 長會議（約 1 萬字）事先算好整份拼音再比，應該在幾十毫秒內；實作時量一次。

## 測試接縫

- **純函式**：小美／小眉、網域／網欲、蔡宜蓁／蔡醫真；跟詞庫一樣的字不算；英文詞跳過；多種寫法的排序和上限。
- **`buildUserMessage`**：有找到時 `<glossary>` 帶註記；沒找到時跟修改前完全一樣。
- **`SYSTEM_PROMPT`**：有說明註記的句子。
- **評測集**：Haiku 4.5 修改前／後各 5 次；Haiku 5.5 medium 5 次。
- **手動**：部署後實機重新分析一場有詞庫的會議。

6. 全部案例各 5 次的輪次用 `--budget 0.8`；整個分支預計約 US$0.4。

## 實作備註

- `findHomophones`（`functions/src/homophones.ts`）：每段逐字稿整段轉一次拼音（多音字照上下文），用跟詞庫詞一樣長的視窗比對；三個字的詞另外用後兩個字比，被全名比對到的位置不再算一次；跟另一個詞庫詞相同的寫法不算。
- `buildUserMessage` 在 `<glossary>` 那一行後面加註；找同音寫法丟錯時不加註、照常分析。
- 速度：最長的真實會議（約 6,000 字）配 200 條詞庫約 0.3 秒；C3、C7 各幾毫秒。
- 評測案例實際找到的註記：C3「蔡宜蓁（一針、蔡醫真）」「吳承翰（乘汗、吳成漢）」；C7「小美（小眉）」「網域（網欲）」；沒有誤判。
