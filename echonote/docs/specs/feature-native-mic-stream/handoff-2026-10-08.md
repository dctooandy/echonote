## 2. 背景：為什麼做這個功能

- 使用者想在技能樹加上 **Flutter `dart:ffi`、MethodChannel**，之後延伸到 C/C++、Rust，所以評估 echonote 適不適合拿來改。
- 現況盤點：echonote 自己的程式碼**沒有** MethodChannel、FFI 或共享記憶體。FFI 只出現在依賴套件 `whisper_ggml` 2.4.0 內部（`DynamicLibrary`、`Isolate.run`、`NativeCallable.listener`），大量資料是用「檔案路徑」傳遞，不經過 Dart。
- 我提出的改法（依投資報酬率排序）：
  1. **MethodChannel／EventChannel**：自己寫原生麥克風串流，給 `WhisperLiveSession` 用 ← **這次的規格就是這一項**
  2. **dart:ffi + C/C++**：fork `whisper_ggml`，做 buffer 重複使用、VAD、修 ffmpeg 引號 bug、縮小 `audio_ctx`
  3. **C 小模組 + FFI**：波形 RMS／降採樣（熱身用）
  4. **Rust**（`flutter_rust_bridge`）：逐字稿後處理。理由最弱，建議最後做或另找題目
- 提醒過使用者：技能樹要寫得誠實，做完這些比較準確的寫法是「Flutter 原生整合（FFI／Platform Channel），修改過 C++ 推論函式庫」，不是「精通 C++／Rust」。

## 3. 討論中確認的關鍵事實

- **即時逐字稿不消耗 AI token**：錄音和 whisper 辨識都在裝置上。唯一的網路流量是第一次下載模型（`base` 約 147 MB）。會花 token 的只有之後手動觸發的 `analyzeMeeting`（Claude Haiku 4.5）。代價轉移到手機的耗電和發熱。
- **`whisper_ggml` 已經有即時 API**：`WhisperController.transcribeLive(model, pcm16Stream: Stream<Uint8List>, lang, ...)` 回傳 `WhisperLiveSession`（`partials` 是完整全文，不是增量；`stop()` 回傳定稿）。**只有純文字，沒有 segments 和時間戳**。`lang` 預設 `'en'`，必須明確傳 `'zh'`。
- **即時預覽不是逐字出現**（讀了 `ios/Classes/whisper_flutter_plus.cpp`）：
  - 累積 1.5 秒以上的新語音才重算一次；
  - 每次重算目前視窗（最多 25 秒），所以最近 25 秒內的文字可能被改；超過 25 秒就定稿；
  - 靜音不觸發重算。
- **延遲風險（推算，未實測）**：whisper 內部會把音訊補滿 30 秒再處理。依離線實測（iPhone 12 Pro Max、`base`、0.37 倍音檔長度，約每 30 秒算 11 秒），每次重算可能要好幾秒。只要超過 1.5 秒，套件的佇列就會無限累積（套件作者在註解裡也承認）→ 所以加了「第 0 步：技術驗證」。
- **git 根目錄在上一層**：`/Users/andychen/Documents/002-development/echonote`，Flutter 專案在子資料夾 `echonote/`。
- **`analyzeMeeting` 的原始碼在 `echonote/functions/src/index.ts`**（我先前誤說不在 repo 裡，已更正）。
- **`functions/node_modules`（7,898 個檔案）和 `functions/lib/` 被 commit 進 git 了**，沒有 `.gitignore` 排除。已在 `master` 用 commit `31a033a` 清掉（`functions/.gitignore` + `git rm -r --cached`）。

## 6. 對照程式碼時發現、已寫進任務的注意事項

- `AppDelegate` 用 `FlutterImplicitEngineDelegate`，channel 要在 `didInitializeImplicitFlutterEngine` 裡透過 `engineBridge.pluginRegistry` 取得 messenger 註冊（T0.3）。
- `Recording.segments`、`elapsedSeconds` 目前是 `final`，要改成可更新（T2.2）。
- 抽出共用轉錄流程時，**不能拿掉** `TranscriptionService._sanitizedAudioPath()`（ffmpeg 路徑沒加引號的 workaround），重構後要用含空白檔名回歸測試（T3.3、T5.2）。
- 即時模式用 `no_context` 而且沒有 prompt，要在技術驗證時確認輸出仍是繁體中文（T0.7）。
- 專案沒有 `CLAUDE.md`。
