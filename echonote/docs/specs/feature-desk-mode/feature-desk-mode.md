# 錄音時的桌面模式 規格

分支：`feature/desk-mode`
狀態：已確認（2026-10-22，4 項待確認事項已決定，見文末「已確認的決定」）
樣稿：<https://claude.ai/artifact/6sqztWevMdtZ43iGtYeTwM> 的「錄音中（桌面模式）」

開會錄音時，手機通常平放在桌上。這時候畫面只需要兩件事：確認還在錄、標記重點；需要的話停止。這份規格讓手機**平放而且穩定**時，錄音畫面自動切成簡化的「桌面模式」，一拿起來就回到完整畫面。

## 背景（2026-10-22 討論）

- 使用者在深色主題討論時提出：「錄音中如果偵測到手機水平，可能已經放在桌上，畫面應該只留下重要功能，例如標記重點、停止，並靠向慣用手那一側。」
- 當時確認的方向：
  - **判斷**：手機平放、螢幕朝上，穩定 3 秒就切換；拿起來馬上回到完整畫面。
  - **畫面**：保留計時、紅點、波形，加上超大的「標記重點」和「停止」；筆記和即時文字開關先收起來。
- 因為要加感測器，從 `feature/dark-theme` 拆出來另外做。

## 現況（寫規格時查過的程式碼）

- **錄音畫面**（`lib/screens/live_record_screen.dart`）：
  - `_Phase.recording` 時畫 `_buildRecording()`：上方是計時、波形；下方操作區是停止鍵（拇指側），旁邊是「標記重點」「筆記」「即時文字」開關。
  - 停止鍵一按就停，不用確認（`_stop`）；標記重點是 `_addStar`，同一秒只記一次。
- **慣用手**：用 `AppSettingsScope.of(context).handedness` 讀（`lib/services/app_settings.dart`）。
- **螢幕常亮**：錄音期間已經保持螢幕開啟（`feature/keep-screen-awake`），所以平放時畫面會一直亮著。
- **感測器**：專案目前沒有任何感測器套件或原生程式。

## 目標與範圍

- 只在**錄音中**（`_Phase.recording`）偵測。準備中、轉錄中、錯誤等其他狀態都不偵測。
- **進入桌面模式**：手機平放、螢幕朝上，連續穩定 3 秒（判斷方式見「權限與狀態機」）。
- **離開桌面模式**：手機一拿起來（不再平放，或晃動）就馬上回到完整畫面。
- **桌面模式的畫面**（照樣稿）：
  - 上方一行小字：「桌面模式・拿起手機顯示完整畫面」。
  - 大的計時和紅點，下面是波形。
  - 兩顆超大圓鍵：「標記重點」（琥珀色）和「停止」（紅色），都在拇指那一側；左手模式時左右對調。
  - 按了標記重點，畫面短暫顯示「已標記 12:47」。
  - 筆記按鈕、即時文字開關、即時文字的內容都不顯示。即時文字如果開著，辨識照常進行，回到完整畫面時文字還在。
- **寫筆記時不切換**：筆記輸入框開著的時候，不進入桌面模式，避免打字打到一半畫面跳走。
- 切換時用淡入淡出的動畫。系統開了「減少動態效果」時直接切換。

**明確不做的事**：

- 螢幕朝下時的處理，例如自動調暗或關閉畫面。
- 調暗亮度、省電處理。
- 首頁和詳細頁的桌面模式。
- 手動進入或離開桌面模式的按鈕（決定 3）。
- 調暗畫面（決定 4）。

## 權限與狀態機

- **權限**：讀加速度計不會跳出授權詢問。但 `sensors_plus` 的說明文件要求 iOS 的 `Info.plist` 一定要有 `NSMotionUsageDescription`，沒有的話存取動作資料時 App 會閃退（套件裡也包含需要授權的氣壓計），所以加上一句說明（T1 修訂）。
- **平放的判斷**（數值為初版，實機再調）：
  - 重力幾乎都在螢幕的垂直方向：z 軸約 −1g，與水平面的傾斜角小於約 10°。
  - 穩定：加速度的變化量很小（沒有在晃動）。
  - 以上兩個條件**連續 3 秒**都成立，才算平放。
  - 任何一筆讀數不成立，就馬上算「拿起來了」。
- **錄音畫面的狀態**：`recording` 之下多一個「桌面模式」的開關狀態，不影響錄音本身的狀態機。離開 `recording`（停止、中斷、出錯）時，感測器跟著停止。

## UI／畫面

以樣稿的「錄音中（桌面模式）」為準。按鈕大小：標記重點約 112、停止約 96，兩顆都有文字標籤。

## 邊界案例與例外處理

- **放在不平的桌面或有微微震動的桌子上**（例如有人打字）：傾斜角和穩定度都要留一點容忍度，實機調整。
- **手機在桌上被輕碰一下**：會短暫回到完整畫面，穩定 3 秒後再進入桌面模式。
- **桌面模式中誤觸停止**：停止鍵很大又放在桌上，比較容易被碰到；使用者決定不防誤觸，一按就停，跟完整畫面一樣（決定 2）。
- **裝置沒有加速度計，或讀不到**：永遠不進入桌面模式，錄音照常。
- **錄音中切到背景**：維持現有做法，停止並存檔；感測器跟著停止。
- **耗電**：只在錄音中開感測器，取樣頻率維持低頻（約每秒 5～10 次）。

## 測試接縫

- **平放判斷**：`FlatDetector` 單元測試：
  - 平放 3 秒後才成立
  - 傾斜或晃動時馬上不成立
  - 輕碰一下後重新計時
- **錄音畫面**：注入假的平放訊號，widget 測試：
  - 平放時切成桌面模式，只剩兩顆大按鈕，筆記和即時文字開關不見了
  - 拿起來回到完整畫面
  - 寫筆記時不切換
  - 桌面模式按標記重點和停止都有作用
  - 左手模式時兩顆按鈕對調
- **實機**：
  - 放在桌上 3 秒後切換，拿起來馬上回到完整畫面
  - 有人敲桌子、打字時不會一直跳來跳去
  - 桌面模式下標記重點和停止都正常
  - 錄 30 分鐘，耗電和現在比較
